# Asteroids: A Raylib C++ Remake


[Animation](https://github.com/user-attachments/assets/aad736b9-8fe6-4d44-8ec6-085e1c4bc02f)

> A modern retro-take of the well known "Asteroids", built from scatch in C++ using the Raylib library. Navigate your ship through a dangerous field of galaxies; destroy them, dodge bombs, collect powerups and compete for the highest score.

---

## Features ##

* **Classic Arcade Playstyle:** Inertia ship movement, sharp shots and splitting galaxies.
* **PowerUps:** Collect diverse powerups to improve your gameplay.
* **Additional enemies:** Dodge the randomly-spawned bombs!
* **Score and lives system** Track your score and manage your lives to reach your maximum score each time.
* **Responsive Design:** A percentage based coordinates system, allowing the game to adapt to any resolution.
* **Diverse Audio:** Tons of sound effects + gameplay and menu audio.

---

## Controls

| Key | Action |
| :--- | :--- |
| **Rigt Click** | Accelerate the ship |
| **Mouse** | Rotate the ship |
| **Left Click** | Shoot |
| **ESC** | Pause / Unpause |

## How to compile and play

This project was built in **C++**.

## Must have

* A C++ compiler

### Compiling (Visual Studio)

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/linthiee/Asteroids.git](https://github.com/linthiee/Asteroids.git)
    
    ```
2.  **Build & Run** using ctrl + f5.
